## 1. Website Overview

A single-page, scroll-told editorial portfolio about one idea: **Khushi makes brands impossible to ignore by connecting the right people.**

The site opens with one continuous cinematic film that the visitor *scrubs with their own scroll*. A thread of molten orange light travels from a potter's wheel in Belagavi, through a constellation of creators in Bangalore, to a packed launch night in Coventry. When the film settles into cream, the thread leaves the video and **becomes the website's orange line**. From there it runs down the whole page, circling numbers, underlining words and pointing at work, until it ends under her email address.

It should feel like **a magazine feature about someone interesting**, set in a good restaurant: calm, clean and warm, with care in every detail and a joke tucked under the plate.

**Primary goal:** get the right person (hiring manager, founder, agency lead, venue owner) to email her.
**Secondary goal:** get them to open her LinkedIn.
**No CV download.** The portfolio does the storytelling; the CV is shared on request.

**Audiences:**
1. Hiring managers and recruiters for marketing, partnerships and BD roles in London.
2. Founders and owners of "zero-stage" brands: new venues, new verticals, family businesses.
3. Agencies looking for a creator/partnerships lead.

## 4. Visual Direction

**Concept: Kiln & Thread.**
The cream of unglazed clay is the page. The orange of the kiln is the thread. The ink is warm, never black. Everything hand-touched sits in orange; everything printed sits in ink.

**Motifs**
1. **The Thread.** One continuous burnt-orange SVG line that draws itself down the page on scroll. It loops around stats, underlines key words, and ends as the underline beneath the email address.
2. **Margin scribbles.** Hand-drawn circles around numbers, arrows pointing at work, wobbly underlines. Each is an SVG path with a slightly irregular stroke that draws on enter.
3. **Clay texture.** Faint paper/clay grain over everything, slightly heavier on sand panels.
4. **Asymmetric editorial grid.** Big type hangs off-centre with plenty of empty space; captions sit in mono like working notes.
5. **Warm-graded photography.** Lifted blacks, warm highlights, visible grain.

**Single dark moment:** **Deep Teal `#1F4A4A`** is used for the Stats band and the Footer only. It's cool against the orange, very editorial, and echoes the deep blue in her reference portrait.

The reference image keeps her consistent across all three.

### 5.2 Generation settings (all clips)
| Setting | Value |
|---|---|
| Model | Higgsfield **Seedance 2.0** |
| Resolution | **1080p (1920×1080)**, 16:9 |
| Duration | **10 s** per clip (allowed range 8–12 s) |
| Frame rate | 24 fps |
| Camera | Slow, continuous, no cuts within a clip |
| Grade | Warm cream highlights, burnt-orange accents, lifted warm shadows, soft 35mm film grain, shallow depth of field |
| Reference | `Media/my-project-page-1.png` (identity) on Scenes 2 and 3; also on Scene 1 for hands and skin tone |
| Negative | no text, no logos, no watermarks, no neon, no cold blue grading, no glossy luxury, no fast cuts, no warped hands, no extra fingers |

### 5.3 Continuity method: one seamless film
The three clips must play as **one unbroken take**.
1. Generate **Scene 1**.
2. Export its **final frame** → use it as the **start frame (image-to-video)** for **Scene 2**.
3. Export Scene 2's final frame → start frame for **Scene 3**.
4. Every prompt describes the **orange light thread** in the same screen position at the start of the clip as it was at the end of the previous one.
5. Concatenate with a 6-frame cross-dissolve at each join to hide any seam (see §21.3).

**Output files** (save to `/assets/video/raw/`):
`scene-1-workshop.mp4` · `scene-2-network.mp4` · `scene-3-launch.mp4`

## 17. Complete Visual Style Guide

### 17.1 Colour tokens
| Token | Hex | Use |
|---|---|---|
| `--cream` | `#F6EFE3` | Page background (matches film end-frame) |
| `--orange` | `#D9541E` | The Thread, scribbles, italic emphasis, primary buttons |
| `--ink` | `#1F1A17` | Text |
| `--terracotta` | `#C07A55` | Tags, hover fills, secondary accents |
| `--sand` | `#EADFCC` | Cards and soft panels |
| `--teal` | `#1F4A4A` | Stats band and footer only |
| `--ink-60` | `rgba(31,26,23,.6)` | Secondary text |
| `--line` | `rgba(31,26,23,.12)` | Hairlines and dividers |

Contrast: ink on cream ≈ 15:1; cream on teal ≈ 9:1; orange used for large type and decoration only (≥24px) or on teal.

### 17.2 Grid & spacing
- 12-column grid, `max-width: 1600px`, gutters `clamp(16px, 2vw, 32px)`, side padding `clamp(16px, 5vw, 96px)`.
- Section padding `clamp(96px, 16vh, 220px)` vertical.
- Spacing scale (px): 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96 · 128 · 192.
- Radius: 2px (cards feel printed, not app-like); pill buttons 999px.

### 17.3 Texture
- Global grain: fixed full-screen pseudo-element using an inline SVG `feTurbulence` noise at 6% opacity, `mix-blend-mode: multiply`, animated with a 6-step `steps()` jitter (8 fps).
- Images: `filter: sepia(.12) saturate(1.05) contrast(1.02)`.

### 17.4 Iconography & scribbles
All scribbles are inline SVG paths, `stroke: var(--orange)`, `stroke-width: 2.5`, `stroke-linecap: round`, deliberately wobbly. Library: circle-1, circle-2, underline-1, underline-2, arrow-curve, arrow-loop, strike, star, pot-doodle.

## 19. Animation Direction

**Principle:** slow in, confident out. Nothing bounces. Everything feels like ink settling or clay turning.

| Token | Value |
|---|---|
| Ease primary | `cubic-bezier(.22,1,.36,1)` (expo-out) / GSAP `expo.out` |
| Ease draw | `power2.inOut` |
| Duration short / base / long | 0.4 s / 0.9 s / 1.4 s |
| Stagger chars / words / items | 0.02 / 0.06 / 0.1 s |

**Kinetic typography catalogue**
1. **Mask rise:** split into chars/lines, `yPercent: 110 → 0`, `rotate: 4 → 0`. Used for all H1/H2.
2. **Scrub reveal:** words fade 0.15 → 1 opacity tied to scroll. Used in Mission.
3. **Italic swap:** emphasised word enters in upright, then morphs into italic via the `ital`/`WONK` axis with a 0.6 s tween.
4. **Velocity skew:** large headlines and the marquee skew (max ±6°) with Lenis velocity.
5. **Count-up:** numbers tick with `snap` and a tabular-nums mono label.
6. **Scribble draw:** `stroke-dashoffset` from length → 0 on enter (0.9 s, `power2.inOut`); margin notes fade and rotate in after the scribble finishes.

**Preloader:** cream screen, mono counter `000 → 100`, label `FIRING THE KILN…`, a small SVG pot outline drawing itself. On complete, the screen wipes up (clip-path inset) revealing the first film frame. Max 2.5 s; it waits for the first 30 frames, not the full sequence.

**Section transitions:** cream → teal transitions use a clip-path curtain (`inset(100% 0 0 0) → inset(0)`) scrubbed over 30vh, never hard cuts.

## 21. Scroll Behavior

- **Lenis** smooth scroll (`lerp: 0.085`, `wheelMultiplier: 1`, `smoothTouch: false`), connected to GSAP's ticker; `ScrollTrigger.update` on Lenis scroll.
- **Pinned sections:** Hero film (500vh), Pillars card stack, Story horizontal track. Everything else flows.
- **The Thread:** a single absolutely-positioned full-page SVG. Its path is **generated in JS** from anchor elements marked `data-thread="x"` (hero underline → stat circle → mission underline → pillar arrows → story track → work arrow → CTA email underline), with smooth cubic Bézier curves between anchors plus a few hand-made loops. It's rebuilt on resize (debounced) and drawn with `stroke-dashoffset` scrubbed to whole-page scroll progress, so the line is always "just ahead" of the reader. It's hidden inside the horizontal Story pin, which has its own local thread.
- **Scroll progress bar:** 2px orange hairline at top.
- **Anchor links** use `lenis.scrollTo(target, { offset: -80, duration: 1.6 })`.

### 21.1 Film scrubbing (hero)
- **Primary: image-sequence canvas scrubbing.** Frames in `/assets/frames/desktop/` (1600px wide WebP, q≈70) and `/assets/frames/mobile/` (900px wide, 4:5 centre crop).
- Sample the 30 s film at **10 fps → 300 frames** (smooth enough with scrub easing, ~12–15 MB total desktop).
- **Progressive loading:** load frames 1, every 10th, then every 5th, then the rest. The renderer always draws the nearest loaded frame.
- Canvas draws with `object-fit: cover` math, DPR-capped at 2, and only redraws when the frame index changes (rAF).
- **Fallback:** if WebP frames are absent but `/assets/video/journey-scrub.mp4` exists, scrub `video.currentTime` instead (all-intra encode). If neither exists, use the animated SVG fallback from §8.

### 21.2 Reduced motion
`prefers-reduced-motion: reduce` → no Lenis, no pin, no scrub. Hero shows the final cream frame + headline; the Thread is drawn fully; counters show final numbers; marquee pauses.

### 21.3 Asset processing commands (run once the clips exist)
```bash
# 1. Join the three clips with soft 6-frame dissolves
ffmpeg -i assets/video/raw/scene-1-workshop.mp4 -i assets/video/raw/scene-2-network.mp4 -i assets/video/raw/scene-3-launch.mp4 -filter_complex "[0][1]xfade=transition=fade:duration=0.25:offset=9.75[a];[a][2]xfade=transition=fade:duration=0.25:offset=19.5,format=yuv420p" -an assets/video/journey.mp4

# 2. Desktop frames (10 fps, 1600w WebP)
ffmpeg -i assets/video/journey.mp4 -vf "fps=10,scale=1600:-2" -c:v libwebp -quality 70 assets/frames/desktop/f_%04d.webp

# 3. Mobile frames (10 fps, 4:5 centre crop, 900w)
ffmpeg -i assets/video/journey.mp4 -vf "fps=10,crop=ih*4/5:ih,scale=900:-2" -c:v libwebp -quality 65 assets/frames/mobile/f_%04d.webp

# 4. Fallback scrub video (every frame a keyframe)
ffmpeg -i assets/video/journey.mp4 -vf scale=1280:-2 -c:v libx264 -g 1 -crf 26 -preset slow -movflags +faststart -an assets/video/journey-scrub.mp4

# 5. Poster
ffmpeg -i assets/video/journey.mp4 -vframes 1 -q:v 3 assets/img/poster.jpg
```
The frame count is written to `assets/frames/manifest.json` so the JS never hard-codes it: `{"count": 300, "mobileCount": 300, "video": true}`. `count`/`mobileCount` switch on frame scrubbing; `"video": true` allows the `journey-scrub.mp4` fallback. With `count: 0` and `video: false` the designed SVG film plays.
